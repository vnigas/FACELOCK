# FaceLock

Приложение для автоматической блокировки экрана компьютера при обнаружении перед камерой человека, чьё лицо не совпадает с зарегистрированным.

## Как это работает

1. Программа раз в секунду делает снимок с веб-камеры.
2. С помощью [DeepFace](https://github.com/serengil/deepface) (модель **Facenet512**) строит embedding — числовой вектор, описывающий лицо на снимке.
3. Сравнивает полученный embedding с сохранёнными в базе (`embeddings.pkl`) через косинусное расстояние.
4. Если расстояние превышает заданный порог — лицо считается "чужим", экран блокируется, а снимок сохраняется в папку с попытками несанкционированного доступа.

Приложение рассчитано на **одного пользователя компьютера**: база хранит embedding'и владельца, и любое лицо, не совпадающее с ними, считается посторонним.

## Стек

- Python 3.11
- [DeepFace](https://github.com/serengil/deepface) — распознавание лиц, модель Facenet512
- OpenCV (`cv2`) — захват видео с камеры
- NumPy, SciPy — работа с векторами и вычисление расстояний
- Pickle — хранение базы embedding'ов
- *(планируется)* [Flet](https://flet.dev) — интерфейс для регистрации пользователя

## Структура проекта

```
FACELOCK/
├── backend/
│   ├── FaceLock.py        # основной цикл распознавания
│   ├── funct.py            # кроссплатформенная блокировка экрана

│   └── known_face/          # фотографии владельца для построения базы

```

## Установка

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com/vnigas/Facelook.git
   cd FACELOCK
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate      # macOS / Linux
   venv\Scripts\activate         # Windows
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Настройка базы лица

1. Поместите одну или несколько фотографий владельца (разные ракурсы, освещение) в папку `data/known_face/`.
2. Поддерживаемые форматы: `.jpg`, `.jpeg`, `.png`.
3. При первом запуске программа автоматически построит базу embedding'ов из этих фотографий и сохранит её в `embeddings.pkl`.

> Чем разнообразнее условия на фотографиях (свет, ракурс, расстояние до камеры), тем надёжнее распознавание. Рекомендуется 5–7 фото.

## Запуск

```bash
python backend/FaceLock.py
```

Приложение начнёт делать снимки раз в секунду и сравнивать их с базой. При обнаружении чужого лица:
- экран блокируется (кроссплатформенно — Windows, macOS, Linux);
- снимок сохраняется в `block_users/` с меткой времени в имени файла.

## Конфигурация

Основные параметры заданы константами в начале `FaceLock.py`:

| Параметр | Назначение | Значение по умолчанию |
|---|---|---|
| `THRESHOLD` | Порог косинусного расстояния для признания лица "своим" | `0.3` |
| `DB_PATH` | Путь к файлу базы embedding'ов | `embeddings.pkl` |
| `IMAGE_DIR` | Папка с фотографиями для построения базы | `data/known_face` |

## Поддерживаемые ОС для блокировки экрана

| ОС | Механизм |
|---|---|
| Windows | `ctypes.windll.user32.LockWorkStation()` |
| macOS | `pmset displaysleepnow` |
| Linux | `gnome-screensaver-command --lock` |
